# Avatar Setup Instructions

## Required Image

Please save the avatar image you provided to:
```
/home/user/llm-chat-mvp/public/images/atagar-avatar.jpg
```

## How to Save the Image

1. Right-click on the anime avatar image you sent
2. Select "Save Image As..."
3. Save it to this directory as `atagar-avatar.jpg`

Alternatively, if you have the image file:
```bash
cp /path/to/your/image.jpg /home/user/llm-chat-mvp/public/images/atagar-avatar.jpg
```

## Image Requirements

- Recommended size: 200x200px or larger (square format works best)
- Format: JPG, PNG, or WebP
- The image will be displayed as a 40x40px circular avatar

## What the Avatar Does

The avatar will appear:
- Next to all assistant messages in the chat
- With a gentle floating animation during normal conversation
- With a pulsing glow animation when the assistant is processing/thinking
